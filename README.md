# 字幕时间轴对齐工具

一个带图形界面（Tkinter）的中英/中外双语歌词字幕时间轴对齐工具。自动识别中文与外文歌词行，把中文歌词的时间轴对齐到对应外文歌词的时间轴，并自动跳过没有对应翻译的孤立行。支持 LRC 等常见歌词格式。

## 功能特性

- 🖥️ 图形化界面，操作简单直观
- 📄 支持 `.lrc` / `.txt` / `.srt` 等文本歌词文件
- 🔤 自动识别 UTF-8 / GBK 等多种文件编码
- 🌐 自动区分中文行与外文行（韩文 / 英文 / 日文等）
- ⏱️ 三种对齐方式（时间匹配 / 中文在前 / 外文在前）
- 🚫 自动跳过无对应翻译的孤立外文行（如纯拟声词）
- 🎨 表格预览 + 颜色标注，结果一目了然
- 💾 结果另存为新文件，原文件保持不变

## 效果示例

**对齐前**

```
[00:14.750]捎在热风中的
[00:14.754]뜨거운 바람에 실린
```

**对齐后**（中文行的时间轴统一到外文行的时间轴）

```
[00:14.754]捎在热风中的
[00:14.754]뜨거운 바람에 실린
```

**孤立外文行**（无对应翻译，保持原样、不会被改动）

```
[00:33.082]你的气场隐约可见
[00:33.082]아른거려 너의 Aura
[00:34.660]Phew phew          ← 孤立外文，无人认领，保持不变
[00:35.248]我的心再次变得滚烫
[00:35.248]다시 뜨거워져 내 맘
```

## 环境要求

- Python 3.7 及以上
- 需要包含 Tkinter（Windows / macOS 官方 Python 安装包自带；部分 Linux 发行版需额外安装 `python3-tk`）

## 快速开始

```bash
python 字幕对齐工具.py
```

> Windows 下若默认 `python` 不含 Tkinter，请改用带 Tkinter 的解释器，例如：
> `C:\Python314\python.exe 字幕对齐工具.py`

## 使用步骤

1. 点击「选择字幕文件…」打开 `.lrc` / `.txt` 文件；
2. 在弹出的对话框中输入从第几行开始对齐（也可在界面选项区修改）；
3. 选择对齐方式（默认「时间匹配」即可）；
4. 点击「开始对齐」，表格中绿色行即被对齐的中文行；
5. 确认无误后点击「保存结果…」，另存为 `原名_aligned.lrc`。

## 对齐方式说明

| 方式             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| 时间匹配（推荐） | 每句中文对齐到**时间戳最接近**、且未被认领的外文行；时间差超过阈值则判定为无对应翻译并跳过 |
| 中文在前         | 中文行下面紧跟一行外文                                       |
| 外文在前         | 外文行下面紧跟一行中文                                       |

「最大时间差（秒）」仅对「时间匹配」生效，默认 1.0 秒。歌词中对应行时间本身很接近时保持默认即可；若对应行时间差较大，可调大该值。

## 界面颜色图例

| 颜色   | 含义                             |
| ------ | -------------------------------- |
| 🟨 黄色 | 中文（待对齐）                   |
| 🟩 绿色 | 已对齐的中文行                   |
| 🟥 浅红 | 未匹配到外文的中文行（跳过）     |
| 🟦 蓝色 | 外文行                           |
| ⬜ 灰色 | 孤立外文行（无需对齐，保持不变） |
